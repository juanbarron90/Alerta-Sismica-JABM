Creador: Juan Antonio Barron Maciel

Plataforma: GitHub Pages · PWA

📡 Datos sísmicos

La aplicación consulta el U.S. Geological Survey (USGS) mediante sus feeds GeoJSON y muestra magnitud, ubicación, profundidad, latitud, longitud y otros datos del evento.

USGS Earthquake CatalogGeoJSON Feed

🔔 Avisos

Puedes elegir la magnitud mínima y los países que quieres vigilar. Los filtros se guardan en este dispositivo.

Importante: una página estática de GitHub Pages no garantiza notificaciones push cuando la web está completamente cerrada. Para avisos fiables en segundo plano se necesita un servicio push/backend.

⚠️ Seguridad

Esta aplicación informa sobre eventos sísmicos reportados; no predice terremotos. En una emergencia sigue siempre las indicaciones de las autoridades.
